# reels-assets

Временный хостинг MP4 рилс @gashenkolak для публикации (GitHub Pages).

- Файлы кладёт рилс-бот (`agencylak-byte/reels-bot`, `src/upload.mjs`): `public/<id>.mp4`.
- Адрес ролика: `https://agencylak-byte.github.io/reels-assets/public/<id>.mp4`.
- После публикации в Instagram публикатор удаляет файл отсюда. Лимит GitHub — 100 МБ на файл, ролики < 95 МБ.
